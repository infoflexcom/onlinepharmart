Prepare this computer, then build Infoflex

Build Studio checks this computer, installs anything missing, and builds the app, the Admin mobile app, both installers and the Vendor Cloud package. You will not need a command prompt at any point.

What you need: this computer, an internet connection for the first run, and the Infoflex project folder. The first build takes a while — the build tools are large and only need installing once.

Is this computer ready?

Build Studio looks for each tool a build needs. A green tick is ready, an orange arrow can be installed by clicking below, and a red cross needs you to do something first.

The Infoflex project

Choose the folder containing the Infoflex files. Build Studio will not change anything outside it except the folder you choose for the built installers.

Build

Press "One-click: do everything" for a complete build, or press a single button to do one part. You can keep using this window while it works, and Cancel stops it.

What is happening

What was built

Each file with its size and fingerprint. The fingerprint lets you check that the file on a USB stick is the one you made.

Copy installer to a USB drive

Plug the drive in, then press Refresh if it does not appear.

Vendor tools

These tools are for the vendor only. Enter the vendor master password to continue. It is checked against the stored fingerprint and is never shown or saved.

Licence key generator

Creates the key pair that signs licences. The public key goes into builds; the private key must be uploaded to the Vendor Cloud as a secret and must never be put in a build or emailed.

Activation helper

How to activate a customer's copy, in each of the three ways it can be done. Nothing here contacts a server.

RouteWhen to use itWhat you do
OnlineThe shop has internetGive the customer their licence key. They type it in the Activation window and the app checks in with the Vendor Cloud.
On-site, offlineThe shop has no internetAt the shop: open Activation → On-site, enter the vendor master password, choose the edition and the dates. The licence is created on that computer and runs for as long as your build allows.
RenewalA licence is running outEither issue a new key online, or repeat the on-site step. The currency is never changed by a renewal.
The on-site term is limited only by the setting in Settings → Maximum on-site licence period, which is embedded in the build. "No limit" lets you issue any term at the shop.
