INFOFLEX BUILD STUDIO

Vendor license policy

Prepare an offline policy file for the desktop host. No password is sent to a server or written to browser storage.

Policy settings

The desktop stores a salted PBKDF2 hash only. Choose an optional on-site term limit; leave it blank for no configured cap. Values above 50 years are intentionally rejected as an operator sanity limit.

●This tool does not use localStorage, cookies, analytics, or network requests. The exported .iflpolicy contains only the salted password hash, period setting, service URL, and public keys.
Installing the policy: place the exported file on the vendor/customer machine and import it in the desktop activation window under On-site / offline → Import vendor policy. Keep the original file for recovery/rebinding. The policy JSON is not digitally signed in this phase; distribute it only through a trusted vendor channel. After import, the desktop protects its saved policy with a local integrity check.
This is a local GUI utility. It does not create or store license signing keys.
